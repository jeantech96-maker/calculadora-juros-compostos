# 🧮 Calculadora de Juros Compostos

Calculadora moderna e responsiva com **Material Design** (verde e branco), desenvolvida com **Bootstrap 5.3** e **Bootstrap Icons**.

---

## ✨ Recursos

* Design moderno e responsivo
* Cálculo com **juros compostos + aportes mensais**
* Tabela com evolução mês a mês
* Resumo de capital, juros e montante final
* Validação de formulário em tempo real
* Animações suaves
* Atalho: `Ctrl + Enter`

---

## 🚀 Como usar

1. Abra o `index.html` no navegador
   ou
2. Rode localmente:

```bash
python -m http.server 8080
# ou
npx serve .
```

---

## 📋 Campos

* Capital inicial
* Taxa de juros (% ao mês)
* Tempo (meses)
* Aporte mensal (opcional)

---

## 🔢 Fórmula

```
M = C × (1 + i)^t + P × [((1 + i)^t - 1) / i]
```
